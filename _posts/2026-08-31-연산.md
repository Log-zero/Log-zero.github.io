### (가) 연산

어떤 집합의 원소들로부터 새로운 원소를 이끌어내는 과정을 <span class="term">연산(Operation)</span>이라 한다. 연산은 하나의 함수로서 정의된다.

집합 $X$에서 정의된 연산 $\ast$의 결괏값이 항상 $X$에 속할 때, $\ast$이 $X$에서 <span class="term">닫혀 있다(Closed)</span>고 한다.

<div class="callout" data-callout="def">
    <div class="callout-title">
        <span class="callout-title-inner">
        <span class="term">이항 연산(Binary Operation)</span>
        </span>
    </div>
집합 $X$에 대하여 $X \times X$에서 $X$로 가는 함수를 $X$에서 정의된 <span class="callout-title-inner"><span class="term">이항 연산</span></span>이라 한다.
</div>

이항 연산은 두 원소들 끼리의 닫혀 있는 연산이다. 두 원소 $x$, $y$에 대한 이항 연산 $\ast$의 함숫값은 $\ast (x, \, y)$ 대신 보통 $x \ast y$로 쓴다. 

### (나) 연산 법칙

연산의 기본 규칙을 <span class="term">연산 법칙(Operation Law)</span>이라 한다.

<div class="callout" data-callout="def">
    <div class="callout-title">
        <span class="callout-title-inner">
        <span class="term">교환법칙, 결합법칙</span>
        </span>
    </div>
집합 $X$에서 정의된 이항 연산 $\ast$과 $X$의 임의의 세 원소 $a$, $b$, $c$에 대하여
<br>
<br>
<ul>
<li>
$a \ast b = b \ast a$일 때,<br>
$\ast$의 <span class="callout-title-inner"><span class="term">교환법칙(Associative Law)</span></span>이 성립한다고 한다.</li><br>
<li>
$(a \ast b) \ast c = a \ast (b \ast c)$일 때,<br>
$\ast$의 <span class="callout-title-inner"><span class="term">결합법칙(Associative Law)</span></span>이 성립한다고 한다.</li>
</ul>
</div>

연산의 결합법칙, 결합법칙은 각각 명제 논리에서의 연결사의 <a href="/2026/03/16/#1-교환법칙">교환법칙</a>, <a href="/2026/03/16/#2-결합법칙">결합법칙</a>과 같다.

연산 $\ast$의 결합법칙이 성립할 적에는 다음 두 연산 

<blockquote>
$(a \ast b) \ast c$<br>
$a \ast (b \ast c)$
</blockquote>

를 따로 구별할 필요가 없으므로, 괄호를 생략하여 간단히 $a \ast b \ast c$로 쓴다. 이제 연산에 쓰이는 원소들이 더 많아도, 이항 연산을 연쇄적으로 수행하여 간단히 연산할 수 있다. 따라서 수학에서는 특별한 경우를 제외하고 결합법칙이 성립하는 이항 연산만 다룬다.

<blockquote>
$a \ast b \ast c \ast d \ast \cdots$
$= ((((a \ast b) \ast c) \ast d) \ast \cdots$
</blockquote>

<div class="callout" data-callout="def">
    <div class="callout-title">
        <span class="callout-title-inner">
        <span class="term">분배법칙(Distribute Law)</span>
        </span>
    </div>
집합 $X$에서 정의된 두 이항 연산 $\ast$, $\diamond$와 $X$의 임의의 세 원소 $a$, $b$, $c$에 대하여
<br>
<br>
<ul>
<li>
a \ast (b \diamond c) = (a \ast b) \diamond (a \ast c)<br>
일 때, $ast$의 $\diamond$에 대한 <span class="callout-title-inner"><span class="term">왼쪽 분배법칙</span></span>이 성립한다고 한다.</li><br>
<li>
(a \diamond b) \ast c = (a \ast c) \diamond (b \ast c)<br>
일 때, $ast$의 $\diamond$에 대한 <span class="callout-title-inner"><span class="term">오른쪽 분배법칙</span></span>이 성립한다고 한다.</li>
</ul>
</div>

연산의 분배법칙도 명제 논리에서의 연결사의 <a href="/2026/03/16/#3-분배법칙">분배법칙</a>과 같다. 왼쪽・오른쪽 분배법칙이 모두 성립할 때, 간단히 분배법칙이 성립한다고 한다. 

### ($2$) 항등원, 역원
<div class="callout" data-callout="def">
    <div class="callout-title">
        <span class="callout-title-inner">
        <span class="term">항등원, 역원</span>
        </span>
    </div>
집합 $X$에서 정의된 이항 연산 $\ast$에 대하여
<br>
<br>
<ul>
<li>
각 $x \in X$에 대하여<br>
$x \ast e = e \ast x = x$<br>
를 만족하는 $e \in X$를 $\ast$의 <span class="callout-title-inner">항등원(Identity Element)</span>이라 한다.
</li><br>
<li>
$\ast$의 항등원 $e$가 존재할 때,<br>
각 $x \in X$에 대하여<br>
$x \ast a = a \ast x = e$<br>
를 만족하는 $a \in X$를 $\ast$에 대한 $x$의 <span class="callout-title-inner">역원(Inverse Element)</span>이라 한다.
</li>
</ul>
</div>

<div class="callout" data-callout="prop">
    <div class="callout-title">
        <span class="callout-title-inner">
        <span class="term">항등원・역원의 유일성</span>
        </span>
    </div>
집합 $X$에서 정의된 이항 연산 $\ast$에 대하여
<br>
<br>
<ul>
<li>
$\ast$의 항등원은 존재하면 유일하다.
<details>
  <summary>증명(누르기)</summary>
<br>
$\ast$의 항등원이 두 개 존재한다고 가정하고, 이를 각각 $e_{1}$, $e_{2}$라 하면<br>
$e_{1} = e_{1} + e_{2} = e_{2}$이다.
</details>
</li>
<br>
<li>
$\ast$의 결합법칙이 성립하고, 항등원이 존재하는 경우<br>
$\ast$에 대한 각 $x \in X$의 역원은 유일하다.
<details>
  <summary>증명(누르기)</summary>
<br>
각 $x \in X$에 대하여<br>
$\ast$의 역원이 두 개 존재한다고 가정하고, 이를 각각 $a_{1}$, $a_{2}$라 하자.<br>
<br>
$\ast$의 항등원을 $e$라 하면<br>
$x + a_{2} = a_{1} + x = e$가 된다. 따라서

<blockquote class="box">
$\begin{align}
a_{1} & = e + a_{1} \\
& = (a_{2} + x) + a_{1} \\
& = a_{2} + (x + a_{1}) \\
& = a_{2}
\end{align}$
</blockquote>

이다.
</details>
</li>
</ul>
</div>

역원은 유일하므로 역원의 역원은 자기 자신이다. 곧, $-(-x) = x$이다.

<div class="callout" data-callout="prop">
    <div class="callout-title">
        <span class="callout-title-inner">
        <span class="term">소거 법칙(Cancellation Law)</span>
        </span>
    </div>
집합 $X$에서 정의된 이항 연산 $\ast$에 대하여<br>
각 $x \in X$의 역원이 모두 존재할 때<br>
$a = b \Longleftrightarrow a \ast x = b \ast x$이다.
<details>
  <summary>증명(누르기)</summary>
<br>
($\Longrightarrow$)<br>
자명하게 참이다.<br>
<br>
($\Longleftarrow$)<br>
$\ast$의 결합법칙에 의하여 다음이 성립한다.

<blockquote class="box">
$\begin{align}
a = a \ast [x \ast (-x)] \\
& = (a \ast x) \ast (-x) \\
& = (b \ast x) \ast (-x) \\
& = b \ast [x \ast (-x)] \\
& = b
\end{align}$
</blockquote>
</details>
</div>

<div class="callout" data-callout="ex">
    <div class="callout-title">
        <span class="callout-title-inner"><span class="term">함수의 합성 연산</span>
        </span>
    </div>
함수의 합성 $\circ$는<br>
교환법칙은 성립하지 않고, 결합법칙은 성립하는 하나의 이항 연산으로 볼 수 있다.<br>
<br>
이때 항등원은 항등함수이고, 역원은 역함수이다.
</div>

### (다) 체
<div class="callout" data-callout="def">
    <div class="callout-title">
        <span class="callout-title-inner">
        <span class="term">체(Field)</span>
        </span>
    </div>
집합 $X$에서 정의된 두 이항 연산 $+$, $\times$이 다음 조건
<br>
<br>
<ol>
<li>
$+$, $\times$는 모두 교환법칙・결합법칙이 성립한다.</li><br>
<li>
$+$에 대한 $\times$의 분배법칙이 성립한다.</li><br>
<li>
$+$, $\times$는 모두 항등원이 존재하고,
이때 두 항등원은 서로 다르다.</li><br>
<li>
임의의 $x \in X$에 대하여<br>
$+$에 대한 $x$의 역원이 모두 존재한다.</li><br>
<li>
$+$의 항등원을 제외한 임의의 $x \in X$에 대하여<br>
$\times$에 대한 $x$의 역원이 모두 존재한다.</li>
</ol>
<br>
을 모두 만족할 때, $X$를 <span class="callout-title-inner"><span class="term">체</span></span>라 하고 $(X, \, +, \, \times)$로 쓴다.
</div>

이때 각 $x \in X$에 대하여 $+$의 역원을 $-x$로 쓰고, $a + (-b)$는 간단히 $a - b$로 쓴다. 이제 체의 부분집합 $S$에 대하여, $S$의 각 원소들에 대한 $+$의 역원들을 모두 모은 집합

<blockquote>
$\{-a \, \mid \, a \in S}$
</blockquote>

를 $-S$로 쓴다.

### ($1$) 순서체
<div class="callout" data-callout="def">
    <div class="callout-title">
        <span class="callout-title-inner">
        <span class="term">양수, 음수</span>
        </span>
    </div>
체 $(F, \, +, \, \times)$의 비어 있지 않은 부분집합 $X$가 다음
<br>
<br>
<ol>
<li>
$a$, $b \in X \Longrightarrow a + b$, $a \times b \in X$</li><br>
<li>
$+$의 항등원을 $e$라 하면
$F = X \cup {e} \cup (-X)$이다.</li>
</ol>
<br>
을 모두 만족할 때, $X$를 $P_{F}$로 쓰고 $P_{F}$의 원소를 <span class="callout-title-inner"><span class="term">양수(Positive Number)</span></span>라 한다. 이때 $-P_{F}$의 원소는 <span class="callout-title-inner"><span class="term">음수(Negative Number)</span></span>라 한다.
</div>

이때 $+$의 항등원 $e$는 양수도 음수도 아니다.

<div class="callout" data-callout="prop">
    <div class="callout-title">
        <span class="callout-title-inner">
        <span class="term">양수와 순서관계</span>
        </span>
    </div>
양수 전체의 집합 $P_{F}$가 존재하는 체 $(F, \, +, \, \times)의 임의의 두 원소 $a$, $b$에 대하여

<blockquote class="box">
$b - a \in P_{F}$ 또는 $a = b$
</blockquote>

일 때 $a \leq b$로 정의하면, $\leq$는 순서관계가 된다.
<details>
  <summary>증명(누르기)</summary>
<br>
임의의 $a$, $b$, $c \in F$에 대하여<br>
<br>
(대칭성)<br>
$a = a$이므로 $a \leq a$이다.<br>
<br>
(반사성)<br>
$a \leq b$, $b \leq a$인 경우<br>
$a \neq b$라 가정하면 $b - a \in P_{F}$이고 $a - b \in P_{F}$이다.<br>
이때 $+$의 항등원 $e$에 대하여<br>

<blockquote class="box">
$\begin{align}
(b-a) + (a-b) & = b + (-a + a) + (-b) \\
& = b - b \\
& = e
\end{align}$
</blockquote>

에서 $e \in P_{F}$이므로 모순이다.<br>
<br>
(추이성)<br>
$a \leq b$, $b \leq c$인 경우<br>
<br>
<ol type="i">
<li>
$a = b$ 또는 $b = c$인 경우<br>
자명하게 $a \leq c$이다.</li><br>
<li>
$a \neq b$이고 $b \neq c$인 경우<br>
$b - a \in P_{F}$이고 $c - b \in P_{F}$이다. 이때

<blockquote class="box">
$\begin{align}
(c-b) + (b-a) & = c + (-b + b) + (-a) \\
& = c - a
\end{align}$
</blockquote>

에서 $c - a$ \in P_{F}$이므로 $a \leq c$이다.</li>
</ol>
</details>
</div>

양수가 존재하는 체는 위와 같이 순서관계를 줄 수 있다. 따라서 양수가 존재하는 체를 <span class="term">순서체(Ordered Field)</span>라 하고, 특별한 언급이 없으면 순서체의 순서관계는 위와 같이 준다. 다음은 순서체에서 연산의 기본이 되는 성질들이다.

<div class="callout" data-callout="prop">
    <div class="callout-title">
        <span class="callout-title-inner">
        <span class="term">순서체의 성질</span> $1$
        </span>
    </div>
순서체 $(F, \, +, \, \times)에 대하여 $+$의 항등원을 $e$, $\times$의 항등원을 $e'$라 하자.<br>
임의의 $a$, $b \in F$에 대하여
<br>
<br>
<ul>
<li>
$a \times e = e \times a = e$
<details>
  <summary>증명(누르기)</summary>
<br>
먼저 $a \times e$가 $+$의 항등원임을 보이자.

<blockquote class="box">
$\begin{align}
(a \times e) + a & (a \times e) + (a \times e') \\
& = (a \times e) + (a \times e') \\
& = a \times (e + e') \\
& = a \times e'
& = a
\end{align}$
</blockquote>

이고, $+$의 교환법칙에 의하여<br>
조$(a \times e) + a = a + (a \times e) = a$이므로<br>
항등원의 유일성에 의하여 $a \times e = e$이다.<br>
<br>
한편, $\times$의 교환법칙에 의하여
$a \times e = e \times a = e$이다.
</details>
</li><br>
<li>
$(-a) + (-b) = -(a + b)$
<details>
  <summary>증명(누르기)</summary>
<br>
$(-a) + (-b)$가 $+$에 대한 $a + b$의 역원임을 보이자.<br>

<blockquote class="box">
$\begin{align}
[(-a) + (-b)] + (a + b) & = (-a) + [(-b) + a] + b \\
& = (-a) + [a + (-b)] + b \\
& = [(-a) + a] + [(-b) + b] \\
& = e + e
& = e
\end{align}$
</blockquote>

이고, $+$의 교환법칙에 의하여<br>
$(a + b) + [(-a) + (-b)] = [(-a) + (-b)] + (a + b) = e$이므로<br>
역원의 유일성에 의하여 $(-a) + (-b) = -(a + b)$이다.
</details>
</li><br>
<li>
$a \times (-b) = (-a) \times b = - (a \times b)$
<details>
  <summary>증명(누르기)</summary>
<br>
먼저 $a \times b$가 $+$에 대한 $a \times (-b)$의 역원임을 보이자.<br>

<blockquote class="box">
$\begin{align}
(a \times b) + [a \times (-b)] & = a \times [b + (-b)] \\
& = a \times e \\
& = e \\
\end{align}$
</blockquote>

이고, $+$의 교환법칙에 의하여<br>
$(a \times b) + [a \times (-b)] = [a \times (-b)] + (a \times b) = e$이므로<br>
역원의 유일성에 의하여 $a \diammond (-b) = - (a \times b)$이다.<br>
<br>
다음으로, $a \times b$가 $+$에 대한 $(-a) \times b$의 역원임을 보이자.<br>

<blockquote class="box">
$\begin{align}
(a \times b) + [(-a) \times b] & = [a \times (-a)] + b \\
& = e \times b \\
& = e \\
\end{align}$
</blockquote>

이고, $+$의 교환법칙에 의하여<br>
$(a \times b) + [(-a) \times b] = [(-a) \times b] + (a \times b) = e$이므로<br>
역원의 유일성에 의하여 $(-a) \diammond b = - (a \times b)$이다.
</details>
</li><br>
<li>
$a \times a \geq e$
<details>
  <summary>증명(누르기)</summary>
<br>
<ol type="i">
<li>
$a = e$인 경우<br>
$a \times a = e \times e = e$</li><br>
<li>
$a$가 양수인 경우<br>
두 양수를 연산한 값도 양수이므로 $a \times a &gt; e$이다.</li><br>
<li>
$a$가 음수인 경우<br>
$-a$가 양수이므로 $a \times a = (-a) \times (-a) &gt; e$이다.</li>
</ol>
</details>
</li><br>
<li>
$e' \geq e$
<details>
  <summary>증명(누르기)</summary>
<br>
$e' = e' times e' \geq e$이고<br>
$e$, $e'$의 정의에 의하여 $e \neq e'$이므로 $e' &gt; e$이다.
</details>
</li>
</ul>
</div>

<div class="callout" data-callout="prop">
    <div class="callout-title">
        <span class="callout-title-inner">
        <span class="term">순서체의 성질</span> $2$
        </span>
    </div>
순서체 $(F, \, +, \, \times)에 대하여 $+$의 항등원을 $e$라 하자.<br>
임의의 $a$, $b$, $x \in F$에 대하여
<br>
<br>
<ul>
<li>
$x &gt; e \Longleftrightarrow -x &lt; e$
<details>
  <summary>증명(누르기)</summary>
<br>
<blockquote class="box">
$\begin{align}
x &gt; e & \Longleftrightarrow x = e + x = e - (-x) \in P_{F} \\
& \Longleftrightarrow -x &lt; e
\end{align}$
</blockquote>
</details>
</li><br>
<li>
$a &lt; b \Longleftrightarrow a + x &lt; b + x$
<details>
  <summary>증명(누르기)</summary>
<br>
<blockquote class="box">
$\begin{align}
a &lt; b & \Longleftrightarrow (b - a) \in P_{F} \\
& \Longleftrightarrow [(b + x) - (a + x)] \in P_{F} \\
& \Longleftrightarrow a + x &lt; b + x
\end{align}$
</blockquote>
</details>
</li><br>
<li>
$a &lt; b$인 경우<br>
$x &gt; e$이면 $a \times x &lt; b \times x$이고,<br>
$x &lt; e$이면 $a \times x &gt; b \times x$이다.
<details>
  <summary>증명(누르기)</summary>
<br>
$b - a$는 양수이다.<br>
만약 $x$가 양수이면 $(b - a) \times x = b \times x - a \times x$도 양수이므로 $a \times x &lt; b \times x$이고,<br>
만약 $x$가 음수이면 $-x$가 양수이다. 따라서 $(b - a) \times (-x) = a \times x - b \times x$도 양수이므로 $a \times x &gt; b \times x$이다.
</details>
</li>
</ul>
</div>

### ($2$) 절댓값
<div class="callout" data-callout="def">
    <div class="callout-title">
        <span class="callout-title-inner">
        <span class="term">절댓값(Absolute Value)</span>
        </span>
    </div>
순서체 $(F, \, +, \, \times)$의 각 원소 $a$의 <span class="callout-title-inner"><span class="term">절댓값</span></span>을<br>
$a$가 음수가 아닐 때 $a$로, $a$가 음수일 때 $-a$로 정의하고 $\mid a \mid$로 쓴다.
</div>

<div class="callout" data-callout="prop">
    <div class="callout-title">
        <span class="callout-title-inner">
        <span class="term">절댓값의 성질</span>
        </span>
    </div>
순서체 $(F, \, +, \, \times)의 임의의 두 원소 $a$, $b$에 대하여
<br>
<br>
<ul>
<li>
$\mid -a \mid = \mid a \mid$
<details>
  <summary>증명(누르기)</summary>
<br>
<ol type="i">
<li>
$a = e$인 경우<br>
$\mid -a \mid = \mid -e \mid = -e = e$이고,
$\mid a \mid = \mid e \mid = e#$이므로 참이다.</li><br>
<li>
$a &gt; e$인 경우<br>
$\mid -a \mid = a = \mid a \mid$</li><br>
<li>
$a &lt; e$인 경우<br>
$\mid -a \mid = -a = \mid a \mid$</li>
</ol>
</details>
</li>
<br>
<li>
$\mid a \times b \mid = \mid a \mid \times \mid b \mid$
<details>
  <summary>증명(누르기)</summary>
<br>
<ol type="i">
<li>
$a$, $b$ 모두 음수가 아닌 경우<br>
$\mid a \times b \mid = a \times b = \mid a \mid \times \mid b \mid$</li><br>
<li>
$a$, $b$ 둘 중 하나만 음수인 경우<br>
$a$가 음수이면<br>
$\mid a \times b \mid = \mid -(a \times b) \mid = \mid (-a) \times b \mid = \mid (-a) \mid \times \mid b \mid = \mid a \mid \times \mid b \mid$이다.<br>
$b$가 음수이면 마찬가지로 참이다.
</li><br>
<li>
$a$, $b$ 모두 음수인 경우<br>
$\mid a \times b \mid = \mid -[-(a \times b)] \mid = \mid -[(-a) \times b] \mid = \mid (-a) \times (-b) \mid = \mid (-a) \mid \times \mid (-b) \mid = \mid a \mid \times \mid b \mid$이다.</li>
</ol>
</details>
</li><br>
<li>
$b$가 음수가 아닐 때<br>
$\mid a \mid b \Longleftrightarrow -b \leq a \leq b$
<details>
  <summary>증명(누르기)</summary>
<br>
($\Longrightarrow$)<br>
<ol type="i">
<li>
$a$가 음수가 아닌 경우<br>
$\mid a \mid = a \leq b$이므로 $-b \leq 0 \leq a \leq b$이다.</li><br>
<li>
$a$가 음수인 경우<br>
$\mid a \mid = -a \leq b$이므로 $-b \leq a &lt; 0 \leq b$이다.</li>
</ol>
<br>
<br>
($\Longleftarrow$)<br>
$\mid a \mid = a$ 또는 $\mid a \mid = -a$이고,
$a \leq b$, $-a \leq b$이므로 $\mid a \mid \leq b$이다.
</details>
</li>
</ul>
</div>

<div class="callout" data-callout="prop">
    <div class="callout-title">
        <span class="callout-title-inner">
        <span class="term">삼각부등식(Triangle Inequality)</span>
        </span>
    </div>
순서체 $(F, \, +, \, \times)의 임의의 세 원소 $a$, $b$, $c$에 대하여
<br>
<br>
<ul>
<li>
$\mid \mid a \mid - \mid b \mid \mid \leq \mid a + b \mid \leq \mid a \mid + \mid b \mid$
<details>
  <summary>증명(누르기)</summary>
<br>
$-\mid a \mid \leq a \leq \mid a \mid$이고 $-\mid b \mid \leq b \mid b \mid$이므로
$-(\mid a \mid + \mid b \mid) \leq a + b \leq \mid a \mid + \mid b \mid$에서 $\mid a + b \mid \leq \mid a \mid + \mid b \mid$이다.<br>
<br>
이제 $\mid a \mid = \mid (a + b) + (-b) \mid \leq \mid (a + b) \mid + \mid b \mid에서
$\mid a \mid - \mid b \mid \leq \mid a + b \mid$이고<br>
$\mid b \mid = \mid (a + b) + (-a) \mid \leq \mid (a + b) \mid + \mid a \mid에서
$\mid b \mid - \mid a \mid \geq \mid a + b \mid$이므로<br>
$- \mid a + b \mid \leq \mid a \mid - \mid b \mid \leq \mid a + b \mid$에서<br>
$\mid \mid a \mid - \mid b \mid \mid \leq \mid a + b \mid$이다.
</details>
</li><br>
<li>
$\mid \mid a \mid - \mid b \mid \mid \leq \mid a - b \mid \leq \mid a \mid + \mid b \mid$
<details>
  <summary>증명(누르기)</summary>
<br>
$-\mid a \mid \leq a \leq \mid a \mid$이고 $-\mid b \mid \leq b \mid b \mid$이므로
$-(\mid a \mid + \mid b \mid) \leq a - b \leq \mid a \mid + \mid b \mid$에서 $\mid a - b \mid \leq \mid a \mid + \mid b \mid$이다.<br>
<br>
이제 $\mid a \mid = \mid (a - b) + b \mid \leq \mid (a - b) \mid + \mid b \mid에서
$\mid a \mid - \mid b \mid \leq \mid a - b \mid$이고<br>
$\mid b \mid = \mid (a - b) + a \mid \leq \mid (a - b) \mid + \mid a \mid에서
$\mid b \mid - \mid a \mid \geq \mid a - b \mid$이므로<br>
$- \mid a - b \mid \leq \mid a \mid - \mid b \mid \leq \mid a - b \mid$에서<br>
$\mid \mid a \mid - \mid b \mid \mid \leq \mid a - b \mid$이다.
</details>
</li><br>
<li>
$\mid a - c \mid \leq \mid a - b \mid + \mid b - c \mid
<details>
  <summary>증명(누르기)</summary>
<br>
$\mid a - c \mid = \mid (a - b) + (b - c) \mid \leq \mid a - b \mid + \mid b - c \mid$
</details>
</li><br>
</ul>
</div>
